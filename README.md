# MLOps Labs

My lab submissions for DADS 7305 - Machine Learning Operations (Northeastern), based on the
[course repo](https://github.com/raminmohammadi/MLOps).

| Lab | Topic | Folder |
|-----|-------|--------|
| 1 | Testing and CI with GitHub Actions | [lab1](lab1/) |

Each lab has its own README with setup instructions and a list of changes from the original.
CI workflows live in `.github/workflows/` at the repo root (GitHub only runs them from there)
and are prefixed with the lab name, e.g. `lab1_pytest.yml`.
